项目概述

《万劫闲仙·清泉岁月》是一款单 HTML 文件的文字选择类修仙游戏。玩家扮演秦荒——天渊宗弟子、万劫钟的敲钟人——在清泉村种地、喝茶、渡劫、不知不觉变强。

核心设计：修炼=过日子，过日子=修炼。种地是力径，喝茶是魂径，修水渠是气径+阵径。不刻意修炼，日子过得好修炼自然涨。

时间跨度：400年（近七甲子），从初到清泉村到四百载将近，四季轮转——春耕、夏长、秋收、冬藏。

核心设定

万劫钟·本命法宝

秦荒生来带的法宝。钟认了他——他是敲钟人。钟要醒，得过一场大劫。天渊宗长老知道这点，送他去裂隙边过劫。

九劫系统

天雷→心魔→血噬→地裂→虚空→业火→天命→轮回→飞升。每劫有前世记忆、独特叙事和属性奖励。渡完九劫可选择飞升或留下。

六径并行

力径·气径·魂径·器径·阵径·劫径，六条路同时走。种地锤力径，喝茶锤魂径，刻纹锤阵径——日常行为自动涨修为。

链式选择

每载四个阶段：春耕→夏长→秋收→冬藏。每阶段的选择引发后续场景和选项，像故事链而非菜单。3个选择/载。

村子状态

水渠、灵果、食物、好感——四个维度跟踪清泉村的变化。村子越好，灵气越厚，修炼越快。

12个结局

扎根/出山/闲仙 × 三甲子 + 沉沦 + 飞升/凡心。没有坏结局——只有不同的活法。

项目演进

第一阶段
都市小说 → 修仙爽文
从《暗账》到《满级大佬回村了》到《万劫武尊》——经历三次赛道转换，最终定位修仙题材
第二阶段
从热血爽文到悠闲修仙
保留劫钟、裂界、六径、前世记忆设定，叙事风格从打脸碾压转为悠闲种田。"死过一次了，这辈子只想好好活着"
第三阶段
去AI痕迹 + 语言质感优化
删掉所有表格/系统化说明/总结性独白。对白改自然混乱，增加感官细节，意象代替叙述
第四阶段
小说 → 游戏
基于小说《万劫闲仙》开发文字选择游戏《清泉岁月》。单HTML文件，链式选择系统，九劫十二结局
第五阶段
九劫完善 + 时间跨度修正
五劫扩展为九劫，时间从400天改为400年（修仙尺度），季节改为春耕/夏长/秋收/冬藏
第六阶段
叙事重构——敲钟人设定
去掉苦大仇深的背叛叙事。万劫钟=本命法宝，长老知情且有意帮忙。秦荒对天渊宗态度看玩家选择
